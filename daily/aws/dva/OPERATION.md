# AWS DVA 定期配信 運用手順（確定版）

最終更新: 2026-03-18

## 1) 配信先・時刻
- 配信先: このDiscordチャンネル
- 配信時刻: 毎日 08:00 JST

## 2) 配信対象
- random配信は停止
- AWS DVA向け配信のみ
- 対象ディレクトリ: `daily/aws/dva/`

## 3) 出力ファイルルール
- 命名: `yyyy-mm-dd.html`
- 同日ファイルが既にある場合は上書きせず `yyyy-mm-dd_ver2.html`, `ver3...`
- 毎回 `daily/aws/dva/latest.html` を最新へ更新

## 4) コンテンツ方針
- 目的: インプット重視（知識蓄積）
- 内容: 毎回オリジナル（使い回し禁止）
- 各トピックの構成:
  1. これは何か（定義）
  2. なぜ重要か
  3. 使いどころ/使い分け
  4. よくある誤解
  5. 3分要点

## 5) コピー導線（必須）
各トピックに必ず以下3ボタンを実装する:
1. トピックの内容をコピー（最重要・必須）
2. 参照リンクをコピー
3. 実践課題のサポートを依頼

## 6) 質問テンプレ形式（固定）
`AWS DVA視点で『トピック名』を、試験と実務の両方で理解できるように整理して。`

## 7) 作業手順の原則
- 直接本番編集は極力避ける
- まず `wip` で作成/検証してから本反映
- 不具合発生時は原因と再実行内容を記録する

## 8) 配信報告フォーマット
毎回この3点を報告する:
- 配信リンク
- 処理時間内訳（企画/本文作成/確認/反映/合計）
- 失敗・再実行の有無
